# alvaroacevedo.dev

Blog personal de Alvaro Acevedo — Backend .NET + IA aplicada, en español.

Construyo en público: MCP servers en C#, agents con Semantic Kernel, RAG en .NET, integraciones con Claude / OpenAI, y patrones de arquitectura backend con IA.

## Stack

- [Astro](https://astro.build/) + [Astro Paper](https://github.com/satnaing/astro-paper) (theme)
- TypeScript
- Tailwind CSS
- Desplegado en [Cloudflare Pages](https://pages.cloudflare.com/)

## Desarrollo local

```bash
npm install
npm run dev
```

El sitio queda en `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```
